# Open in Brave (Chrome extension)

1. Install Python 3 (python.org; on Windows tick "Add Python to PATH").
2. Run the installer:  `python install.py`  (double-click works too)
3. Chrome -> chrome://extensions -> Developer mode ON -> Load unpacked -> choose the `extension` folder.
4. Open a YouTube video, then: click the toolbar button, press Alt+B, or right-click a link -> "Open in Brave".

Do not move this folder after running install.py (re-run it if you do).
